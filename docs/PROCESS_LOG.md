## 第 5 轮：Bug 复现与修复

- **Bug：周视图列头显示周二~周六**。用户报告后用 browser-use（390×844 视口）复现成功
- 根因：JS 数组 0 起始，`WD[w]`（w 从 1 开始）取标签偏一天；`WD[d.getDay()]` 在周日的映射也是错的
- 修复：业务索引 WD（1=周一）与 JS 索引 WDS（0=周日）分离，标签统一 `WD[w-1]` / `WDS[getDay()]`
- 回归验证：列头周一~五 ✓；月视图 8 月全月学期外 ✓；9/1(周二) 仅第5节六.4 ✓；10/1(周四) 三节课 ✓
- 教训：**涉及"第 X 个"的语义（星期、节次），必须先写清楚索引基准再动手；改动后要在真实视口尺寸下渲染验证，不能只看代码**

## 2026-08-30 第 11 轮：周视图改回"节次行网格"（参考现成课表项目）

重构：

- 调课交互双模式：①点选（点课块→点空格→弹窗选 仅当天/整学期）②按住拖动（手指按住课块移动，目标格虚线高亮，松手弹窗）；假期/学期外照常可操作
- 已验证（browser-use）：列头"周一 8/31"格式 ✓；假期周空格子 ✓；开学周点选调课闭环（四.6 周三P3→周五P4，ADJ 正确、两日课程同步变化）✓

遗留：拖动手势在 browser-use 里因输入通道延迟未自动化验证，需用户手机实测；拖动与页面滚动的冲突已用 touch-action:none + 12px 位移阈值规避。

## 2026-08-30 第 12 轮：调课模型重构为"日期覆盖表"（修复重复课程/无法撤销）

用户实测发现：多次调课后出现重复课程、无法撤销。根因：ADJ 移动记录列表在多次叠加时边界情况算不清，且周视图重构后撤销入口丢失。

**模型重构**（治本）：
- 废弃 ADJ 移动记录列表，改为 OVR 日期覆盖表：{ "2026-09-02": [{p,cls,adj} 全天课程列表] }
- 调课 = 源日期列表移除一项 + 目标日期列表添加一项（添加前清同格），每格天然唯一，结构上不可能重复
- 覆盖列表与基课表一致时自动删除（存储不膨胀）
- 撤销：HIST 快照栈（保留20步），周导航栏新增"撤销"按钮，逐步回退
- 月视图关闭拖拽（调整统一在周视图），删除 FullCalendar eventDrop/eventClick 的 ADJ 遗留
- 空格子不可作为调课源（防 undefined 班级）

**验证**（browser-use，数据层直接调用 applyMove）：
- 三重叠加调课（四.6→周五P4、六.3→周一P4、六.1→周三P3）：五个工作日无重复、无丢失 ✓
- 连续三次撤销：OVR 清空、五日课程完全还原基表 ✓
- GUI 单次流程（点选→弹窗→仅当天→撤销按钮）：通过 ✓

经验：多步 GUI 自动化受输入通道延迟/重复影响不可靠，数据层用直接函数调用验证，GUI 只做单流程冒烟；真机手感仍需用户实测。
