# 教师课表助手 · 需求与决策记录

> 单学科多班级小学教师（郑文娟，信息技术，荔城区西天尾中心小学）的个人课表与日程工具。
> 本文档是项目的唯一事实来源：新会话/新开发者/未来的自己，从这里恢复全部上下文。

## 1. 背景与目标用户

- 使用者：单教师，跨 4 个年级 14 个班（四.1～四.7、六.1～六.7），每班每周 1 节课，共 14 节/周
- 核心场景：每天在安卓手机上快速查看"今天第几节、几点、去哪个班"
- 次要场景：记录每日待办；管理跨多日的长期任务（备赛、备考，甘特图式）

## 3. 硬性约束（用户明确要求，任何版本都必须遵守）

1. **UI 中禁止 emoji**（用文字或普通符号 ■ □ + ✕）
2. **手机竖屏全宽适配**，周视图不允许出现横向滚动

4. 数据/待办仅存本地，无云端、无账号体系
5. 中文界面

## 4. 数据格式

### timetable.json（主数据，既是导入格式也是存储参考）

```json
{
  "school": "荔城区西天尾中心小学",
  "semester": "2026-2027学年第一学期",
  "teacher": "郑文娟", "subject": "信息技术",
  "start_date": "2026-09-01", "end_date": "2027-01-27",
  "lessons": [
    {"weekday": 1, "period": 3, "start": "10:25", "end": "11:05",
     "subject": "信息技术", "class": "六.5"}
  ]
}
```

- `weekday`：1=周一 … 5=周五；`period`：节次号；时间跟随节次（作息表）
- 每节课一条记录；14 条；每班每周恰好 1 节（四.1~四.7、六.1~六.7 各 7 节）
- 注意坑：**JS 数组 0 起始**，weekday→星期文字标签时必须 `WD[w-1]`（本项目踩过：列头显示成周二~周六）

### 派生格式

- `timetable.csv` — 人工核对用（UTF-8 BOM，Excel 直接开）
- `timetable.ics` — 导入安卓日历 App（14 个 VEVENT，WEEKLY RRULE 至 2027-01-27，Asia/Shanghai）
- `timetable_wakeup.xlsx` — WakeUp 课程表导入格式（列：课程名称/星期/开始节数/结束节数/老师/地点/周数；周数 1-22，App 内开学日期须设为 2026-09-01）
- WakeUp 模板来源：`/Users/kw/Downloads/vivo办公套件/课表模板.xlsx`

### 原型内部数据模型（正式版沿用）

- 基课表 `lessons`：[weekday, period, class]
- 临时调课 `ADJ`：{date, from:[wd,p], to:[wd,p], cls}，只影响指定日期
- 长期调课：直接改基课表
- 待办 `TODOS`：{id, date, text, done}
- 有效课程 = 基课表按星期展开 + 当日临时调课覆盖，学期外为空
- 存储：原型 localStorage（键 `tt_data`/`tt_adj`/`tt_todos`）；正式版换 SQLite/Isar

## 5. 原型（prototype/timetable_app.html）

- 单文件 HTML，无依赖、无构建，数据内置+localStorage
- 运行：本机 `python3 -m http.server 8080`（在 prototype 目录），手机同局域网访问 `http://<电脑IP>:8080/timetable_app.html`；也可微信传文件直接用浏览器打开
- 已实测通过（2026-08-29，浏览器 390×844 视口）：周视图列头周一~五、月视图学期过滤、9/1 与 10/1 课程明细正确
- 已知交互限制：临时调课只能调到本周的格子；长按 400ms 触发拖拽

## 6. 技术选型记录（正式版）

推荐路线：**Flutter 自研**，纯本地无后端
- 已决策（2026-08-30）：原型层采用 FullCalendar（MIT），拖拽/月周视图由其负责
- 周课表视图：JonasWanke/timetable 或 werner-scholtz/kalender
- 月/周切换：kongpf8848/smart_calendar 或 r_calendar
- 日期区间选择（R8 用）：calendar_date_picker2
- 甘特条带：insideapp-srl/flutter_gantt 或月视图自绘跨日条
- 数据模型参考：WakeupSchedule_Kotlin（节次×星期×周次）
- 备选成品：WakeUp 课程表（已验证可导入，但无多班视角/待办/甘特）

图片课表识别：直接用多模态大模型读图输出 JSON + 人工核对，无需 OCR 引擎

1. 每完成一轮"用户反馈 → 修复"，立即追加 PROCESS_LOG.md（反馈内容/处理方式/根因/验证方法）
2. 新产生的需求澄清写入 REQUIREMENTS.md §2，新决策写入 §3 或对应章节，未做的写入 §9 开放问题
